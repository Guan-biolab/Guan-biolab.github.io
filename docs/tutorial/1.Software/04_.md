# 共享软件使用流程



---

###### 更新时间：20241018

集群共享软件使用流程：

1、查看集群中共享软件使用说明文件，确认软件是否已安装，及安装位置；

/platform_data/Software/0.共享软件使用说明文件_20240931更新.txt

2、根据查询到的位置信息，尝试从conda调用或者直接调用

3、软件命令 --help 查看软件使用说明及参数详情

4、sinfo 查看集群队列、节点信息

4、选取小样本量，复制修改作业模板，用sbatch提交作业

5、squeue查看队列中的作业信息，确认是否提交成功 （状态ST: R正在运行）

6、查看输出结果文件夹，跟踪输出结果是否正确。

**7、结果无误后，修正作业程序，正式提交大数据集运行。**
